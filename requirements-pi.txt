# NOTE: picamera2 is intentionally NOT listed here. modules/ocr.py now
# captures from the CSI camera via the rpicam-still command-line tool
# (already installed system-wide on every Raspberry Pi OS image) instead
# of the picamera2 Python module. This avoids a real, common failure:
# apt-installed picamera2/libcamera Python bindings are compiled for one
# specific Python version and cannot be imported from a different venv
# (e.g. a separate Python 3.11 venv created because mediapipe does not
# yet support Python 3.13). If you ever need picamera2 directly for your
# own code, install it via apt (sudo apt install python3-picamera2) and
# create your venv with --system-site-packages using the SAME Python
# version as your system Python — never pip install it into a
# differently-versioned venv, it will not work. See CHANGES.md.
